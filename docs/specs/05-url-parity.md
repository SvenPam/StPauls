# Spec 05: URL parity

_One session. Makes every live URL resolve exactly as it does today, without trailing slashes, adds the XML and HTML site maps, handles old mixed-case and account links, and adds a URL check script for migration and cutover. See the [design](../design-site-replacement.md) and [conventions](conventions.md)._

---

## Goal

Every URL in the live sitemap, and every old link variant seen in live markup, either serves the same page with 200 or is redirected on purpose, and a script can prove it against a build or a deployed site.

## Starting point

- Specs 02 to 04 on `main`. Internal links have no trailing slash (`href.html`), but Static Web Apps serves both `/x` and `/x/` with 200, so search engines see duplicates.
- `site/static/staticwebapp.config.json` holds only `responseOverrides`. `baseURL` is `/`. The `sitemap` kind is disabled.
- Live: 116 URLs in `http://stpaulswarton.co.uk/sitemap.xml`, an HTML site map at `/sitemap`, and links in live markup to `/Calendar`, `/Notices`, `/Contact`, `/Account/Login`, `/Account/Register`.
- [Checked facts](conventions.md#azure-static-web-apps): file paths are case-sensitive, route case sensitivity is unknown, redirects cannot use captures, the config is limited to 20 KB.

## In scope

- `baseURL = 'https://stpaulswarton.co.uk/'`. Canonical link on every page.
- `staticwebapp.config.json` generated by Hugo from `site/data/legacy.yaml`, with `trailingSlash: "never"`.
- `sitemap.xml` with no trailing slashes, `robots.txt`, and an HTML `/sitemap` page.
- `tests/fixtures/live-urls.txt`, a snapshot of the live sitemap paths plus the variants above.
- `scripts/check_urls.py`, run by hand against a build or a deployed host.

## Out of scope

Legacy upload paths (spec 07 adds them to `legacy.yaml` as it copies the files). Security and cache headers (09). The custom domain (11).

## Requirements

### `site/data/legacy.yaml`

```yaml
# rewrite: serve the target with 200. Safe whatever the route case rules are.
rewrites:
  - { from: /Calendar, to: /calendar/index.html }
  - { from: /Notices, to: /notices/index.html }
  - { from: /Contact, to: /contact/index.html }
  - { from: /Blog, to: /blog/index.html }
# redirect: only where the target can never match the route.
redirects:
  - { from: "/account*", to: "/" }
  - { from: "/Account*", to: "/" }
```

### Generated `staticwebapp.config.json`

| | |
|---|---|
| How | Output format `swaconfig` on home (`mediaType = 'application/json'`, `baseName = 'staticwebapp.config'`, `isPlainText = true`, `notAlternative = true`), template `site/layouts/home.swaconfig.json` built with `dict` and `jsonify` |
| `trailingSlash` | `"never"` |
| `routes` | Each rewrite as `{ route, rewrite }`, then each redirect as `{ route, redirect, statusCode: 301 }` |
| `responseOverrides` | `404`: `{ rewrite: /404.html, statusCode: 404 }` |
| Guards (tests) | Valid JSON, under 20,480 bytes, no redirect whose target matches its own route pattern, every rewrite target exists in the build |
| Deleted | `site/static/staticwebapp.config.json` |

### Site maps

| | |
|---|---|
| `sitemap.xml` | Template `site/layouts/sitemap.xml`. Every rendered regular page, section and term page, absolute URLs on `https://stpaulswarton.co.uk` without trailing slash (home stays `https://stpaulswarton.co.uk/`). Excludes `404`, `/sitemap` and taxonomy list pages. `lastmod` from `.Lastmod` |
| `robots.txt` | `enableRobotsTXT = true` with template `site/layouts/robots.txt`: allow all, `Sitemap: https://stpaulswarton.co.uk/sitemap.xml` |
| `/sitemap` | `site/content/sitemap.md` (`title: Site Map`, `layout: sitemap`). Lists Home, Blog with its articles, Calendar with upcoming events, Notices with notices, then each page type with its pages. Not in Pages CMS |

### Canonical

`head.html` adds `<link rel="canonical" href="{{ .Permalink | partial "href.html" }}">`. On the test URL this points at the real domain, which is intended.

### `tests/fixtures/live-urls.txt`

One path per line, sorted, no host, no trailing slash: every `<loc>` in the live sitemap (fetched in Task 3), then the variants `/Calendar`, `/Notices`, `/Contact`, `/Account/Login`, `/Account/Register`, `/account/manage`. A comment line at the top with the fetch date. It is a fixture: it does not change when Paul edits content.

### `scripts/check_urls.py`

| | |
|---|---|
| Usage | `python3 scripts/check_urls.py --list tests/fixtures/live-urls.txt --built site/public` or `--base https://<host>` |
| `--built` | For each path, pass when a file exists at `<built>/<path>/index.html` or `<built>/<path>`, or the built `staticwebapp.config.json` has a route matching it exactly (or by its trailing `*` prefix) |
| `--base` | For each path, `GET` without following redirects. Pass on 200, or on 301 or 302 when the path matches a configured redirect. Anything else fails |
| Output | One line per failure, then a summary `N checked, M failed`. Exit code 1 when any failed |
| Dependencies | Standard library only (`urllib.request`, `json`, `argparse`) |
| Not in CI | Never called from the workflow or the test suite. The test suite tests its functions against fixtures |

## Implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every live URL and known variant resolves, proven by a script.

**Architecture:** Hugo generates the Static Web Apps config from a data file, so routes live next to the content they serve and tests can check them. Case variants are rewrites, which cannot loop. A standalone script compares a list of live paths with a build or a host.

**Tech Stack:** Hugo extended 0.167.0 (custom output formats), Azure Static Web Apps routing, Python 3 standard library.

**Spec:** the sections above, from Goal to Acceptance. Shared rules and names in [conventions](conventions.md).

### Global Constraints

- Everything in [conventions: global constraints](conventions.md#global-constraints).
- `legacy.yaml` keys exactly `rewrites` and `redirects`, entries exactly `{ from, to }`. Spec 07 appends to both.
- No `redirect` route whose target could match its own `route`.
- The URL check never runs in the deploy workflow.

### Review Focus

1. A redirect that loops on Static Web Apps because routes match case-insensitively. Expected: impossible by construction. Pinned by `test_no_redirect_can_loop`.
2. Old links with a trailing slash (`/blog/article/x/`), as Facebook and search engines hold them. Expected: one 301 to the slash-less URL, never a 404. Pinned by `test_trailing_slash_never` and the post-merge check.
3. A generated config over 20 KB once spec 07 adds upload routes, which Static Web Apps would reject at deploy. Pinned by `test_config_size`.
4. The sitemap listing the 404 page or unrendered page-type sections. Pinned by `test_sitemap_contents`.
5. `check_urls.py --base` treating a redirect to the wrong place as a pass. Pinned by `test_unexpected_redirect_fails`.

```python
def matches(pattern: str, path: str) -> bool:
    """Static Web Apps route match, case-insensitive to be safe: exact, or prefix when pattern ends with *."""

def test_trailing_slash_never(self):
    self.assertEqual(self.cfg["trailingSlash"], "never")

def test_case_variants_are_rewrites(self):
    rw = {r["route"]: r["rewrite"] for r in self.cfg["routes"] if "rewrite" in r}
    self.assertEqual(rw["/Calendar"], "/calendar/index.html")
    self.assertEqual(rw["/Contact"], "/contact/index.html")

def test_account_links_redirect_home(self):
    rd = {r["route"]: (r["redirect"], r["statusCode"]) for r in self.cfg["routes"] if "redirect" in r}
    self.assertEqual(rd["/account*"], ("/", 301))
    self.assertEqual(rd["/Account*"], ("/", 301))

def test_no_redirect_can_loop(self):
    for r in self.cfg["routes"]:
        if "redirect" in r:
            self.assertFalse(matches(r["route"], r["redirect"]), r)

def test_rewrite_targets_exist(self):
    for r in self.cfg["routes"]:
        if "rewrite" in r:
            self.assertTrue((self.out / r["rewrite"].lstrip("/")).is_file(), r)

def test_config_size(self):
    self.assertLess((self.out / "staticwebapp.config.json").stat().st_size, 20_480)

def test_404_override(self):
    self.assertEqual(self.cfg["responseOverrides"]["404"], {"rewrite": "/404.html", "statusCode": 404})

def test_canonical(self):
    page = (self.out / "notices/notice/newer/index.html").read_text()
    self.assertIn('<link rel="canonical" href="https://stpaulswarton.co.uk/notices/notice/newer">', page)
```

```python
def test_sitemap_contents(self):
    xml = ET.fromstring((self.out / "sitemap.xml").read_bytes())
    ns = {"s": "http://www.sitemaps.org/schemas/sitemap/0.9"}
    locs = [l.text for l in xml.findall("s:url/s:loc", ns)]
    self.assertIn("https://stpaulswarton.co.uk/", locs)
    self.assertIn("https://stpaulswarton.co.uk/page/about/about-us", locs)
    self.assertIn("https://stpaulswarton.co.uk/calendar/event/16/mu-advent-carol-service", locs)
    self.assertIn("https://stpaulswarton.co.uk/blog/topic/website", locs)
    for bad in ("/404", "/sitemap", "/page/about", "/blog/topic"):
        self.assertNotIn("https://stpaulswarton.co.uk" + bad, locs)
    self.assertEqual([l for l in locs if l.endswith("/") and l != "https://stpaulswarton.co.uk/"], [])

def test_robots(self):
    self.assertIn("Sitemap: https://stpaulswarton.co.uk/sitemap.xml", (self.out / "robots.txt").read_text())

def test_html_sitemap(self):
    html = (self.out / "sitemap/index.html").read_text()
    self.assertIn("<h1>Site Map</h1>", html)
    for href in ("/blog", "/blog/article/a8", "/calendar", "/notices", "/page/about/about-us", "/contact"):
        self.assertIn(f'href="{href}"', html)
    self.assertNotIn("Fixture past", html)
```
